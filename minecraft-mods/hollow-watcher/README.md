# Hollow Watcher — experimental alpha

For Minecraft Java **1.20.1 with Forge 47.3.0 or compatible 47.3+**.

[Download the mod JAR](./hollowwatcher-1.20.1-0.1.0.jar?raw=true) · [Installation instructions](./INSTALL.txt)

Put the JAR into your Forge instance’s `mods` folder. No GeckoLib is required. Test in a new world first: the creature can damage crops, wooden doors, gates, and glass. Use `/gamerule mobGriefing false` to disable its block damage.

This is a compiled experimental alpha. The Forge build, 15 memory-policy checks, 14 resource checks, and four headless Forge game tests passed. Graphical appearance, live stalking encounters, and multiplayer balance still need hands-on testing. It deliberately ignores creative/spectator players. See INSTALL.txt for a quick survival-mode test.
